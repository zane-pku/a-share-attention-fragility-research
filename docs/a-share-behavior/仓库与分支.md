# 仓库与分支

这套研究用一个总入口，从研究目录链接到数据源、可复用工具和接入分支。汇总表只维护一份，避免每个仓库各存一份指标公式和验证状态。

| 角色 | 仓库入口 | 适合放什么 |
|---|---|---|
| **研究总库** | [市场情绪与脆弱性研究](https://github.com/zane-pku/a-share-attention-fragility-research) 的 [行为指标目录](https://github.com/zane-pku/a-share-attention-fragility-research/tree/mangrove/a-share-contrarian/docs/a-share-behavior) | 指标 ID、家族、证据、组合条件、回测与试验记录。默认页负责导航 |
| 行业拥挤度计算 | [A 股交易拥挤度](https://github.com/zane-pku/a-share-crowding-research) · [行业导出](https://github.com/zane-pku/a-share-crowding-research/tree/mangrove/sector-crowding) | 成交份额、规模修正、头部与退出约束。原公式在因子库，输出适配在分支 |
| 社区聚合 | [原社区指数 fork 的适配分支](https://github.com/zane-pku/baoma-xiaobai-sanhu-zhishu/tree/mangrove/community-attention) | 来源席位、文本表达、覆盖率、缺测与时间规则 |
| 短线接力 | [Vibe AStock fork 的适配分支](https://github.com/zane-pku/vibe-astock/tree/mangrove/shortline) | 昨日涨停表现、炸板、晋级，以及短线收盘聚合 |
| 市场接入演练 | [市场风险适配](https://github.com/zane-pku/a-share-attention-fragility-research/tree/mangrove/market-risk) | 样例与市场数据的离线合成、时点判断、覆盖展示和平台候选文件 |
| **平台消费** | [Mangrove 投研平台](https://github.com/zane-pku/mangrove-platform) | 经验证的指标序列、看板和刷新入口。研究表描述的是接入候选及状态 |
| 研究参照 | [Bagholder 50](https://github.com/zane-pku/bagholder50) · [CNEquity](https://github.com/zane-pku/CNEquity) · [AKShare](https://github.com/zane-pku/akshare) | 纯行情对照篮子、历史股票池和交易所字段。Fork 保留上游形态，引用时标明版本 |
| 扩展资料 | [另类数据雷达](https://github.com/zane-pku/a-share-attention-fragility-research/tree/mangrove/alt-data-radar/docs/alt-data-radar) | 夜光、港口、开源开发和美股披露等跨市场线索，供专项研究 |

维护次序建议为 **写清研究定义 → 验证来源和时间 → 记录历史检验 → 在对应仓库生成标准输出 → 平台验收**。一次指标定义变更在研究总库登记，一次来源采集或输出格式修改在相应适配分支记录。平台只需引用稳定的指标 ID 和方法版本。
