# GitHub 上的有趣 A 股行为研究

核验日期 2026-11-27。按用途筛选了六个项目，优先看能不能把一个说法拆为可审计的输入、事件时钟和结果。下表的研究结果、词典和语料均需分别核对其来源与许可。

| 项目 | 哪个想法值得借鉴 | 当前证据边界 |
|---|---|---|
| [冷西西韭菜50指数，已 fork](https://github.com/zane-pku/bagholder50) | 把“最容易被追涨的一篮子股票”变成每日可记录的 Top50。四项分别看价格追涨、换手放大、龙虎榜注意力、特大单流量；收盘出分，下一开盘到再下一开盘计理论等权收益。保留预热、缺测和方法版本 | MIT。已核对模型配置和方法正文。它测的是交易行为代理，特大单等字段不能识别散户身份。收益为理论毛收益，缺口、涨跌停成交、费用、融券另测 |
| [follow-stock-kol](https://github.com/hanniballei/follow-stock-kol/tree/9a6a1889aef67d1138e2ddffc388399984b4a107) | 按日汇编 X 上的股票博主观点，每条摘要保留原帖链接。可借鉴原帖—主题—标的—时间的证据链及每天归档 | 覆盖多市场，包含 A 股片段。公开摘要缺少逐条可重放的固定 A 股博主面板和反转验证。未见明确许可证，作为方法参考 |

另有一个有用的 **纯行情反证基准**。[Market-sentiment-index](https://github.com/Quantify-hp/Market-sentiment-index/tree/3a2337d4af0e111186c85731429a08225dcdf2a7) 的九项温度计和测试代码可参考。只有在相同事件、相同覆盖条件下，加入博主信号能够改善纯行情基准，才有理由保留这个数据源。

## 可以直接从这些项目衍生的三个试验

1. **博主开口之前，行情走了多远。** 借 KOL 日报的原帖证据结构。从预定的博主池第一次明显同向表态起算，反查在此之前行业已跑赢全A多少，以不同提前量分组。保留明确否定、没有表态和采集失败的区别。
2. **网红在讲、社区在问、市场在交易。** 博主同向度、普通社区操作问询率、Top50 拥挤篮子或现货参与面各设一栏。把“声量和看多同时高但宽度掉队”与“热度和宽度一起增加”比较，分别看个股、行业与宽基。
3. **单个博主的事件图，只作为研究线索。** 固定事前的纳入理由并保留所有可判定方向的事件。自称买入、表达看多、讨论热点分别编码，不把自述当真实成交。把该作者和同领域固定对照组比较，加入没有反转的案例，避免只挑形成梗的事件。

金融自媒体还可能补充市场原有的信息供给。微信公众号研究发现，披露质量低的公司往往得到更多分析类自媒体关注。这个机制应作为“高热就是追涨过度”的对照，用正式公告日期和原文事件标注做控制。[《金融市场中自媒体的信息生产》](https://ccj.pku.edu.cn/Article/DownLoad?id=365403449&type=ArticleFile)
