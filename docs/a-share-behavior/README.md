# A 股行为情绪与反向指标

这次优先整理**财经博主、散户问询、话题破圈和真实承接**。正文精选 13 个观察。底表归档 88 项口径，涵盖此前三套研究的 69 条登记和本轮19条新增口径。这里的条目包含原始量、计算中间量、基准和事件条件，数量不能用来衡量独立因子的数量。

## 最值得先留档的五个

| 指标 | 观察什么 | 怎样验证它有用 |
|---|---|---|
| **网红集体喊多指数** | 事前固定一组公开财经内容创作者。每个作者、每个行业、每天一票，计算明确表态的作者中有多大比例看多。并列展示活跃作者数、表达明确的作者数和看多人数 | 在相近过去涨幅、波动和公告环境下，比较高共识后的行业5/20日超额收益。先检验是否只是价格上涨的跟随 |
| **网红追热点迟到** | 行业已经先涨，非金融渠道讨论开始扩散，财经博主群才第一次形成明显同向表态。把上涨、话题扩散、博主表态三个时间分别存下来 | 同样上涨和破圈的行业中，比较博主早响应、晚响应和没有响应，控制政策或行业新闻 |
| **价格没跌，网红先退潮** | 价格仍贴近20日高点，博主看多率开始下滑。作品少、抓取失败、撤稿要另外标记 | 比较同样高位、同样高热度、但方向尚未回落的行业。从相对收益和最大回撤分别检验 |
| **大家开始问怎么买** | 数开户、交易规则、怎么买等操作型问询。把“怎么解套”“要不要补仓”另属持仓修复表达 | 同一平台内做季节和覆盖校正，再看行业成交、ETF份额或月度开户是否开始响应。提问代表表达意图，无法据此判断身份和是否入金 |
| **视频很热，但没人进一步找软件** | 短视频热点升温时，行情软件搜索、下载或使用是否跟上。三者各按自身历史标准化 | 先用周频两条序列比，再与开户月报交叉核对。平台算法变更、下载统计换源或营销活动要单列 |

***最像“宝妈指数”的组合*** 是 **「大家开始问怎么买」×「话题真的破圈」×「盘面承接是否跟上」**。可先对照两类情形。第一类是注意力外溢后，行业赚钱面和成交份额继续改善。第二类是讨论继续扩散、价格仍高，成分股和短线接力已经走弱。两组分别看未来行业超额收益，允许延续、反转和无增量三种结论。

精选表还包括股吧看多后转冷、解套求助降温、热搜超出涨幅解释的部分、昨日涨停今天集体被套、ETF越跌越申购、开户和基金发行同热等。ETF及宽基现有结果沿用前次检验，社区与博主候选需要经授权、有首见时间的真实历史，此轮未据此做社交数据回测。

## 研报和公众号提供了哪些实际做法

- **跨平台跟同一个词，观察热度接力。** 华创证券《鼎沸：牛市中的自媒体》用2024年9月至10月的观察窗口，分别整理微信、百度、抖音、小红书、快手等平台。研究中的先后顺序适用于这次个案，借鉴点是保存平台时序和关键词类型。2026年投资者温度计周报则继续把内容热度、软件下载和开户分栏。这里将三者建成不同证据字段。[华创专题](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/lastest/rptid/783382178247/index.phtml) · [华创周报](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/strategy/rptid/848836029704/index.phtml)
- **极值与拐点分开。** 华泰情绪温度计讨论了A股热度持续和冷端阴跌。渤海行业报告按行业自身两年窗口计算五个分位，并讨论高低端在不同行业波动组的表现。借鉴点是分别建状态和触发事件，并为主题业务单设行业相对收益。[华泰作者发布稿](https://finance.sina.com.cn/wm/2026-03-18/doc-inhrkfux7605158.shtml) · [渤海报告摘要](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/strategy/rptid/846588693204/index.phtml)
- **关注与情绪方向要分别存。** A股股吧发帖量可作为注意力代理。个股注意力、行业注意力和市场关注度有不同的解释范围。建议用过去收益和公告做匹配，再检验博主方向是否增加信息。[A股显著性研究](https://www.sciencedirect.com/science/article/abs/pii/S0927538X25003749) · [多层级关注研究](https://coaa.istic.ac.cn/openjournal/periodicalArticle/0120260401706715)

三组易混淆口径。**提及份额、看多率、实际申购**分别反映注意力、公开表达和产品行为。**赚钱面、上涨家数、站上均线比例**分别用基准、零收益和均线作参照。**ETF份额变化、估计净申赎金额、期末规模变化**分别记录份数、金额和规模，避免把净值上涨混入申赎。C8的组合信号用对应底层指标复算，和子项一起放进模型时应检查重复权重。

## 首轮博主试验如何做

1. **先定名单和主题。** 依公开内容领域选财经创作者，按渠道冻结名单和生效日期。普通讨论、财经博主和机构官方账号作为不同观察组。保留停更者，换名单时开新版本，避免只留后来走红的人。
2. **保存首次可见版本。** 把长视频、直播切片和逐字转载聚为同源，作者日最多一票。反讽、转述、复述盘面、表达不清单标未判定。只保存有授权的数据和必要证据，展示聚合数值。
3. **冻结起始检验参数。** 例如试运行要求至少两个来源组、至少8名明确表达方向的独立作者、预定采样入口覆盖不少于80%。正式历史分位以此前最多252个交易日、最少126个有效日作为候选起始值，阈值待冻结后做样本外验证。作者覆盖、明确方向样本和可见数据不足时留空。用同日历、同过去收益波动、同公告状态的行业对照，保留政策冲击案例和反方向案例。
4. **先看层级与期限，再考虑复合分。** 宽基做市场后续变化，行业做相对全A，个股用自身行业对照。比较5、20日以及隔日进入，报告去重后的事件数、负例和低覆盖。博主方向、人气和承接先分屏显示。

现有脚本和回测明细仍在 [A股反向指标研究](https://github.com/zane-pku/a-share-attention-fragility-research/tree/mangrove/a-share-contrarian/docs/a-share-contrarian) 中。
